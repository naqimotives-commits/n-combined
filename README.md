# N Combined: deploy in ~10 minutes (free)
1. Create a free account at vercel.com and a free GitHub account.
2. Upload this folder as a new GitHub repo, then "Import" it in Vercel.
3. In Vercel > Settings > Environment Variables add:
   ANTHROPIC_API_KEY  (console.anthropic.com, paid per use)
   PEXELS_KEY         (pexels.com/api, free)
   PIXABAY_KEY        (pixabay.com/api/docs, free)
4. Redeploy. Your site is live at yourname.vercel.app.
